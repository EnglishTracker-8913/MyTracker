    💾 Data Management & Auto-Backup

    हर save पर अपने आप snapshot बनता है; पुराने Session भी safe हैं। यह tracker अभी browser/local storage पर चलता है, इसलिए सिर्फ same ID से दूसरे device पर अपने-आप वही data नहीं दिखेगा। दूसरे device या नए tracker version में वही data + वही login accounts ले जाने के लिए नीचे वाला Portable HTML download करें।

    अगर tracker को दूसरे device में खोलना है या updated tracker file में पूरा data + login IDs साथ ले जाना है, हमेशा Download Portable Tracker (HTML) use करें। दूसरे device में उसी file को सीधे खोल सकते हैं, या इस tracker में Import Backup / Portable HTML से data merge कर सकते हैं।

    ☁️ Cloud Sync (Real-time, Multi-Device)

    आपकी email से secure login जोड़ दिया गया है — अब सिर्फ आपकी email/password से sign in करने पर ही data दिखेगा, बाकी किसी के पास file पहुंच भी जाए तो data नहीं खुलेगा।

    एक बार का Setup:
    1) Firebase Console → Build → Authentication → Get started → Sign-in method → Email/Password को Enable करें।
    2) उसी में "Users" tab → Add user → अपनी email + कोई password डालें (यही आगे हर device पर sign in करने के काम आएगा)।
    3) नीचे Firestore Rules अपडेट करें (नीचे दिया गया code, अपनी email डालकर, paste करें)।
    🔐 Cloud Login
    🔒 Signed in नहीं हैं — पहले Sign In करें
    🔴 Not connected
    ⚠️ Security note: अब असली सुरक्षा आपकी email/password से आती है। Firestore rules को request.auth != null वाले नए rule से update जरूर करें (नीचे दिया code), वरना login होने पर भी data खुला रह सकता है।
